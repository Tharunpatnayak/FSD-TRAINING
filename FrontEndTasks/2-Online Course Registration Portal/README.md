# Online Course Registration Portal

## Project Information

**Project Title:** Online Course Registration Portal
---

## Project Description

The Online Course Registration Portal is a responsive web application developed using HTML5, CSS3, and Bootstrap 5. The portal allows students to explore available courses, view course details, register online, learn about the institute, and contact the training center.

The application is fully responsive and provides a user-friendly experience across mobile, tablet, and desktop devices.
