# College Event Management System

## Project Overview

The College Event Management System is a responsive web application developed using HTML5, CSS3, and Bootstrap 5. The website allows students to view upcoming college events, register for events, check event schedules, browse event galleries, view FAQs, and contact event coordinators.

The application is fully responsive and works on mobile, tablet, and desktop devices.
