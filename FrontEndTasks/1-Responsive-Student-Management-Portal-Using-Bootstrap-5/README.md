# Responsive Student Management Portal Using Bootstrap 5

## Project Information

**Project Title:** Responsive Student Management Portal Using Bootstrap 5

---

## Project Description

The Responsive Student Management Portal is a web-based application developed using HTML5, CSS3, and Bootstrap 5. The portal provides an intuitive and responsive interface for managing student information, registrations, attendance records, results, student profiles, and communication. The website is designed to work seamlessly across mobile, tablet, and desktop devices.
