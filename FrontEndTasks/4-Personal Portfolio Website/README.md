# Personal Portfolio Website

## Project Information

**Project Title:** Personal Portfolio Website
---

## Project Description

The Personal Portfolio Website is a responsive web application developed using HTML5, CSS3, and Bootstrap 5. The website showcases personal information, educational background, technical skills, projects, achievements, certifications, internships, and contact details in a professional manner.

The portfolio is designed to provide a modern and responsive user interface that works seamlessly across mobile, tablet, and desktop devices.
